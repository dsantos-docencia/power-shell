# 🌱 Community scripts

**🌍 Language / Idioma:** **English** · [Português](README.md)

This folder is a **collaborative catalog**: useful PowerShell scripts submitted by people in the community, curated and credited.

> **Want to submit yours?** Open an issue via the **"📜 Submit a script to the community"** track ([new issue](https://github.com/dsantos-docencia/power-shell/issues/new/choose)). We review it, comment, and, if it makes sense, include it here with your credit. *Don't let the knowledge die with you.*

## How the curation works

1. You submit the script (issue or PR) and tell us what problem it solves.
2. We review it together: clarity, safety (no surprise destructive effects), and whether it passes PSScriptAnalyzer.
3. We adjust whatever is needed — always keeping **your credit as the author**.
4. It lands here, with a standard header and a line in the index below.

## A community script's standard

Each script carries a header like this:

```powershell
<#
============================================================================
  Community script · <name>
  Author: <Your Name> (@your-user)
  Curation: Prof. Daniel Santos' PowerShell repository
  License: PolyForm Noncommercial 1.0.0 (noncommercial use) — see /NOTICE.md
  What it does: <one line>
============================================================================
#>
```
