## Como funciona o padrão de tradução

Cada arquivo de conteúdo tem a versão original (`README.md`, em português) e, ao lado, a versão traduzida com o sufixo do idioma: **`README.en.md`** (inglês), `README.es.md` (espanhol), etc. — seguindo os códigos [BCP-47](https://en.wikipedia.org/wiki/IETF_language_tag).

```
modulos/00-introducao-paradigma/
├── README.md        ← original (pt-BR)
├── README.en.md     ← inglês
└── README.es.md     ← espanhol (exemplo)
```

Regras simples:
- **Traduza o texto, não o código.** Nomes de variáveis, comandos e a saída dos exemplos continuam como estão (eles são testados). Traduza comentários e narração quando ajudar.
- **Mantenha os links relativos** apontando para os mesmos arquivos (eles são compartilhados entre idiomas).
- **Mantenha o cabeçalho de autoria e licença.**
- No topo de cada arquivo, deixe o seletor de idioma apontando para as outras versões.

## Quer traduzir?

1. Escolha um arquivo com 🚧 (ou comece um idioma novo).
2. Abra uma issue dizendo o que vai traduzir (evita trabalho duplicado).
3. Crie o arquivo `*.<idioma>.md` ao lado do original.
4. Abra um Pull Request. Você entra em [CONTRIBUTORS.md](../CONTRIBUTORS.md) e mantém o crédito da tradução.

Mesmo traduzir **um módulo** já ajuda muita gente. Obrigado! 💚
